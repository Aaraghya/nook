Privacy Policy

Effective: November 25, 2026

Nook is a desktop application for Windows. This policy explains what Nook stores on your computer, how it uses it, and what it does not do. It is written to match the application as it exists today. If anything changes, this page will be updated.

1. Data Nook stores

Clipboard history (ClipStack)

Nook watches the Windows clipboard and keeps a history of the text you copy so you can find and re-copy it later. Only text is captured — images, files, and other clipboard formats are ignored. Each entry is capped at 100,000 characters, and the history holds up to 100 entries; pinned entries are kept first when the limit is reached.

Clipboard history is held in memory only while Nook is running. Nothing is written to disk, and the history disappears when you quit the app.

Snippets

Snippets you save are stored in a local SQLite database file on your computer at %APPDATA%\com.pocket.desktop\pocket.db. Each snippet contains the label, content, category, and timestamps you gave it. Snippets are stored as plain text and remain on your PC across restarts until you delete them in the app.

Now Playing

Nook reads the track currently playing on your PC — title, artist, album, artwork, and playback progress — through Windows' built-in media controls (the same information shown in the Windows volume flyout). This is read-only: Nook never changes what you are playing. The artwork is held in memory to display it and is not written to disk.

2. Application data and Windows integrations

  • Local application data. Nook and its components may store working files under %APPDATA%\com.pocket.desktop and %LOCALAPPDATA%\com.pocket.desktop. The interface is rendered by the WebView2 system component, which keeps its own cache under %LOCALAPPDATA%\com.pocket.desktop\EBWebView.
  • Global shortcut. Nook registers the Alt+Space shortcut so you can open or hide it from anywhere. To keep that shortcut working while Nook is closed, it also registers a lightweight helper in your Windows startup entries (the registry value NookHotkeyWatcher under HKCU\Software\Microsoft\Windows\CurrentVersion\Run). You can remove it from Windows Settings under Apps → Startup, or by deleting that registry value.
  • System tray. Nook places an icon in your taskbar notification area so it can stay quietly available.

3. What Nook does not do

In its current version, Nook has no accounts, no sign-in, no analytics, no telemetry, no advertising, and no crash-reporting code. We are not aware of any functionality that transmits your data outside your computer. Please note that system components outside our control — such as Windows itself or the WebView2 runtime — may perform their own background activity (for example, checking for updates) that Nook cannot prevent.

4. Third-party services

Nook does not currently integrate any third-party services. The only third-party component in use is Microsoft's WebView2 runtime, a Windows system component used to display the interface.

About a future Google Calendar integration: a Calendar feature using Google sign-in is not part of the current application. Nook does not request Google OAuth, does not access the Google Calendar API, does not create calendar events, and does not store Google tokens. Before any such integration is ever released, this policy will be updated to describe the sign-in process, the permissions requested, and how tokens are stored.

5. Your control and deleting your data

  • Clipboard history is held in memory and is removed when you quit Nook.
  • Snippets can be deleted individually from within the app at any time.
  • Storage files remain on your computer after uninstalling unless you remove them. To erase everything, delete the folders %APPDATA%\com.pocket.desktop and %LOCALAPPDATA%\com.pocket.desktop.

6. Security and retention

Snippets are stored locally in a SQLite database without application-level encryption. Clipboard history is held in memory while Nook is running and is not persisted to disk. Access to this data depends on the security of your Windows account and device.

Clipboard history lives only while Nook is running. Snippets are kept until you delete them or remove the storage folders described above.

7. Children

Nook is a general-purpose desktop application and is not specifically directed at children. Nook does not require an account or intentionally collect personal information from users. Users are responsible for the content they choose to store in the application.

8. Changes to this policy

This policy may be updated as Nook changes, including before any future feature that handles data differently (such as a Calendar integration). Updates will be posted on this page with a new effective date.
