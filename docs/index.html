Three small tools, one quiet home

Nook keeps the everyday things within reach, without getting in your way.

Now Playing

Shows the track currently playing on your PC — title, artist, album, artwork, and progress — by reading Windows' built-in media info. Read-only: it never touches your music.

ClipStack

A clipboard history for the text you copy. Search it, copy any clip back, and pin the ones that matter. Kept in memory while Nook runs.

Snippets

Save the text you reuse — links, replies, code — into categorised snippets. Stored locally on your PC, searchable, and there whenever you reopen Nook.

Run from source

For developers and tinkerers. Clone the repository and follow the four steps below to run or build Nook yourself.

View on GitHub

Prerequisites

  • Git — to clone the repository and work with the code.
  • Node.js and npm — to install and build the web frontend. The current LTS release is a good choice.
  • Rust toolchain — installed via rustup, with the MSVC host toolchain for Windows.
  • Visual Studio C++ Build Tools — with the “Desktop development with C++” workload, required by Tauri 2 on Windows.
  • WebView2 runtime — needed to display the interface. It comes preinstalled on Windows 10 (version 1803 and later) and Windows 11.

Build steps

  1. 1

    Clone the repository

    Download the source and move into the project folder.

    git clone https://github.com/Aaraghya/nook.git
cd nook
  2. 2

    Install dependencies

    Downloads the packages the frontend needs.

    npm install
  3. 3

    Run the development version

    Compiles the Rust backend, launches the app, and reloads as you edit. The first run takes a few minutes.

    npm run tauri dev
  4. 4

    Build the release installers

    Creates a production build. The output lands in src-tauri/target/release/:

    • Installer (NSIS): src-tauri/target/release/bundle/nsis/Nook_0.1.0_x64-setup.exe
    • Installer (MSI): src-tauri/target/release/bundle/msi/Nook_0.1.0_x64_en-US.msi
    • Standalone executable: src-tauri/target/release/nook.exe
    npm run tauri build

Node.js and Rust are only needed to build or develop Nook — a packaged installation from the releases page doesn't require them. Building from source also requires about a gigabyte of free disk space for the toolchain and build output.
